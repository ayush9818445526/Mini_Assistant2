## 🚀 **Quick Start Guide**

### 🔧 **Automatic Setup**
```bash
python setup_tara.py
```
This will:
- Install all dependencies
- Configure ElevenLabs voice (optional)
- Setup voice recognition
- Test all systems
- Create shortcuts

### 🎬 **Manual Setup**
```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Configure ElevenLabs API (optional)
# Edit config.py and add your API key

# 3. Run TARA
python main.py
```

### 🎤 **First Interaction**
1. TARA's animated face will appear
2. Say "Hey TARA" to wake her up
3. Watch her face light up with excitement!
4. Start talking naturally - she'll understand
